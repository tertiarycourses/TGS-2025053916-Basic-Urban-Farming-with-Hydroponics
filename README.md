# Basic Urban Farming with Hydroponics

WSQ courseware for **TGS-2025053916**, developed by Tertiary Infotech Academy Pte Ltd.

This v2.0 release is a highly visual, mechanism-led introduction to hydroponic urban farming. It covers root-zone control, system selection, water and nutrient management, crop health, current Singapore production cases, a guided farm tour, hydroponics-kit practice and aquaponics theory.

## Delivery Flow

1. Morning theory and technical knowledge
2. Lunch
3. Guided farm tour
4. Hydroponics-kit practice
5. Aquaponics theory
6. Written and practical assessment

## Current Singapore Context

The release uses the current Singapore Food Story 2 framing: by 2035, Singapore aims to maintain local production capacity equivalent to 20% of fibre needs and 30% of protein needs. Case studies include ComCrop, Sustenir, Singrow and the Greenphyto vertical-farm project. See the source register for primary references and claim boundaries.
